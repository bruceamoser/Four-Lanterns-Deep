## Included

Deeds origins, development, tiered signatures, pure and hybrid Forge progression, action resolution, ward upkeep and recovery. The delve introduces unknown potions, paid and field identification, wearable training gates, creature drops, tools, rare resurrection and a vault with two routes and an alarm. The release still contains all 58 approved creature models plus the licensed Dungeon Mason player assets.

## Verification

398 automated tests. Migration from a real-engine synthetic 0.8.8 battle preserved the party, reserve, Hall, return passage, gear, XP, injuries and spent Grit. The silent direct launcher passed Ubuntu AppArmor and seccomp checks, save-on-close, Forge/respec, four-hero combat controls and the vault-to-appraisal walkthrough. The licensed AppImage passed the infirmary, camp, AI, music and update-control smoke tests. The 0.8.8 AppImage rejected corrupt update bytes, blocked installation on a failed save and restarted into 0.9.0 with the test journey intact. Two runtime archives matched the 58 approved creature hashes. Seeded results for 256 floors, 2,048 scripted pickups and 128 combat drills are in the [rules and balance report](../../deeds-conversion.md).

## Delivery

Eight locally staged assets matched their GitHub draft digests. The [finished installer workflow](https://github.com/bruceamoser/Four-Lanterns-Deep/actions/runs/46082166276) passed the AppImage, installed Debian package and installed Windows NSIS build and published the release as latest.
